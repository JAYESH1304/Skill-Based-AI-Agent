# Instructions

### Document Structure
1. **Start with a clear title** that summarizes the document's purpose
2. **Include an introduction** that sets context and outlines what will be covered
3. **Organize content in logical sections** with clear headings
4. **End with a conclusion** that summarizes key points

### Writing Style
- Use clear, professional language appropriate for the audience
- Keep paragraphs focused on one main idea
- Use transitions between sections for smooth flow
- Be concise while providing sufficient detail
- Avoid jargon unless appropriate for the target audience

### Formatting Best Practices
- Use markdown formatting for structure:
  - `#` for main title
  - `##` for section headings
  - `###` for sub-sections
  - `-` or `*` for bullet points (use sparingly)
  - `**bold**` for emphasis (use sparingly)
  - `>` for important quotes or callouts

### Common Document Types

**Reports:**
- Executive Summary (if long)
- Introduction/Background
- Main Findings/Analysis
- Recommendations
- Conclusion

**Articles:**
- Engaging introduction
- Main body with supporting points
- Examples or evidence
- Conclusion with takeaway

**Essays:**
- Introduction with thesis
- Body paragraphs with topic sentences
- Evidence and analysis
- Conclusion

## Important Notes
- Always ask for clarification if the document's purpose or audience is unclear
- Adjust formality based on context (business report vs. blog post)
- Consider the document's length requirement
- Focus on clarity and readability over complex vocabulary
